# 🌌 Advanced Exoplanet Observatory

An AI-powered full-stack scientific platform for detecting and analyzing exoplanets from astronomical light curve datasets. The application provides an interactive research dashboard, dataset management, preprocessing pipelines, transit detection, visualization tools, and AI-assisted scientific reporting.

## ✨ Features

- 🚀 Modern React + TypeScript frontend
- ⚡ FastAPI backend with REST APIs
- 📊 Interactive research dashboard
- 📁 Dataset upload and management
- 🌌 Light curve preprocessing
- 🔭 Exoplanet transit detection pipeline
- 📈 Scientific data visualization
- 🤖 AI-assisted research insights
- 📄 Automated report generation
- ☁️ Cloud deployment with Vercel and Hugging Face Spaces
